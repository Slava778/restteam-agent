Політика конфіденційності RestTeam Agent

Оновлено: 15.11.2026.

Які дані отримує застосунок

Застосунок працює з Google Диском власника ресторанів через дозвіл drive.file. Він створює папки, завантажує фото й відео з робочої групи Telegram і дописує рядки в таблицю «Каталог материалов». Інших файлів на Диску застосунок не бачить і не читає.

Як використовуються дані

Файли зберігаються тільки на Google Диску власника. Застосунок не продає дані, не передає їх третім особам і не використовує для реклами. Використання даних, отриманих через API Google, відповідає Google API Services User Data Policy, включно з вимогами Limited Use.

Зберігання доступу

Ключ доступу зберігається на сервері застосунку у файлі, доступному лише службовому користувачу. Власник може будь-коли відкликати доступ: myaccount.google.com → «Безпека» → «Сторонні застосунки» → RestTeam Agent → «Видалити доступ».
